# Internationalization (planning only — Phase 7)

English + 22 scheduled languages: Assamese, Bengali, Bodo, Dogri, Gujarati,
Hindi, Kannada, Kashmiri, Konkani, Maithili, Malayalam, Manipuri, Marathi,
Nepali, Odia, Punjabi, Sanskrit, Santali, Sindhi, Tamil, Telugu, Urdu.

- No ad hoc string translation in components before this layer exists.
- Affects UI, topics, current affairs, AI feedback, evaluation, achievements,
  profile, errors. Language persists per user.
- Variable text length; per-script lazy font loading (Devanagari, Bengali,
  Gurmukhi, Gujarati, Kannada, Malayalam, Odia, Tamil, Telugu, Perso-Arabic,
  Ol Chiki, Meitei Mayek).
- RTL for Urdu (and Perso-Arabic Kashmiri/Sindhi): use logical CSS properties.
- Fallback: requested locale → English.
- Controlled glossary (debate, motion, defend, oppose, switch, preparation,
  rebuttal, conclusion, score, current affairs, difficulty, leaderboard);
  AI translation assists but never overrides glossary terms.
- `<html lang="en">` is hardcoded in Phase 0; Phase 7 makes `lang` and `dir` dynamic.
